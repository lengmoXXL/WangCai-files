# 旺财文件视图（files）

旺财右侧的目录视图：翻目录，点一个文件把它交给 editor 插件。

顶部一行是 base 路径：框里写着它，左边的按钮把它放回工作区；再下面才是列。图片、渲染后的 Markdown 与 HTML 归
preview 插件。

点目录在这一列后面开一列。文件走的是终端里点文件链接那条 `onclick`；反方向也成立——别处发来的目录链接
落在这里。

一列不够宽时，拖它右边那条边可以拖宽，宽出来的地方由面板横向滚动让出。

## 配置

在 `~/.config/wangcai/init.ts` 的标签页条目里写 `config`，改完重启 App 生效：

```ts
tabs: [
  { id: 'files', config: { font: { family: '"DejaVuSansM Nerd Font Mono", monospace' } } },
  // 点开的文件交给它，所以它也要在列表里。
  { id: 'editor' },
  { id: 'terminal' },
],
```

`font.family` 是面板的字体，默认 `Menlo, monospace`。

## 键

`<leader>f`（默认 `<C-Space>f`）把本视图调到前面。

每列是一个 Vim buffer，一行一个文件名。普通模式可以用 `5j`、Visual 选择和 yank，也能直接进入插入模式。

| 键 | 作用 |
| --- | --- |
| `h` / `l` | 在文件名内左右移动 |
| `j` / `k`（或 `↓` / `↑`） | 上下移动光标；按住不放会一直走，到这一列的两头停下 |
| `gg` / `G` | 跳到光标所在列的第一个 / 最后一个 |
| `L`（或 `→`、`Enter`） | 进入光标所在的目录，文件则交给 editor 插件 |
| `H`（或 `←`） | 回到上一层目录 |
| `D` | 把光标上的文件下载到本机的 `Downloads` |
| `/` | 在右上角打开搜索框 |
| `i` / `a` | 在当前栏进入插入模式 |
| `=` | 预览已编辑的目录变更 |

搜索框查按下 `/` 时光标所在的栏。输入时光标跳到首个命中，`↓` / `↑` 在命中之间移动。
按 `Enter`、`Esc` 或点击列区可关闭搜索框，光标留在选中的那一项上。点目录可以直接进入。

## 编辑目录

直接在当前栏按 `i` 或 `a` 改名字。用 `o` 或 `O` 加一行来新建条目，新目录名以 `/` 结尾。
写 `abc/123.md` 可以在子目录新建文件。把 `notes.md` 改成 `abc/notes.md` 可以移动文件，缺少的上级目录会一并创建。
可以用 `:%s/旧名/新名/g` 一次改多行。

跨栏移动时，用 `dd` 或 `V` 选整行后按 `d`，到目标栏按 `p` 或 `P`。按 `H` 可以切到父目录。
直接移除整行，按 `=` 会预览删除。应用后，删除的文件或目录会移到所在机器的废纸篓。
用 `yy` 或 `V` 选整行后按 `y`，再粘贴，可以复制文件或目录。
按 `Esc` 回到普通模式，按 `=` 一起预览当前 Files 标签页里已编辑的目录。
按 `Enter` 或 `y` 应用，按 `Esc` 或 `n` 返回 buffer。切换目录时可继续编辑，`u` 可以撤销还在 buffer 里的操作。

## base 路径

列从 base 路径开始，默认是工作区的路径，框里写着它。`H` 走到最上面那一列时，再按一次把 base 抬到它的上一层，
视图跟着上去一层，光标落在刚离开的那一项上；从那里再往下走，抬高的 base 就成了左边那几列的起点。
左上角的按钮把 base 放回工作区的路径，抬出去的那些列随之收起；base 已经是工作区时按钮不可点。

## 下载

右键一个文件选「下载到 Downloads」，或把光标停在文件上按 `D`。文件从它所在的机器拷一份到本机的 `~/Downloads`，
名字照旧。本机已经有一个同名文件时新的那个加编号（`a.txt`、`a-1.txt`、`a-2.txt`），不覆盖已有的。目录不下载。

## 标签页

一个窗口给每个工作区留一份本插件的标签页，各显示各的列。
还没有显示目录的标签页，打开时取的是当时终端的目录（之后终端换目录不会再跟）。
