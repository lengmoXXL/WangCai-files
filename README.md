# 旺财文件视图（files）

旺财右侧的目录视图：翻目录，点一个文件把它交给 editor 插件。

它没有自己的头部行——面板上直接就是列；图片、渲染后的 Markdown 与 HTML 归 preview 插件。

点目录在这一列后面开一列。文件走的是终端里点文件链接那条 `onclick`；反方向也成立——别处发来的目录链接
落在这里。

一列不够宽时，拖它右边那条边可以拖宽，宽出来的地方由面板横向滚动让出。

## 配置

在 `~/.config/wangcai/init.ts` 的标签页条目里写 `config`，改完重启 App 生效：

```ts
tabs: [
  { id: 'files', config: { font: { family: '"DejaVuSansM Nerd Font Mono", monospace' } } },
  // 点开的文件交给它，所以它也要在列表里。
  { id: 'editor' },
  { id: 'terminal' },
],
```

`font.family` 是面板的字体，默认 `"DejaVuSansM Nerd Font Mono", monospace`。

## 键

`<leader>f`（默认 `<C-Space>f`）把本视图调到前面。

面板拿到焦点后（打开它、点它里面）就收这些键。光标画成某一行上的一圈高亮，`j` / `k` 只在它所在的那一列里移动：

| 键 | 作用 |
| --- | --- |
| `j` / `k`（或 `↓` / `↑`） | 上下移动光标 |
| `gg` / `G` | 跳到光标所在列的第一个 / 最后一个 |
| `l`（或 `→`、`Enter`） | 进入光标所在的目录，文件则交给 editor 插件 |
| `h`（或 `←`） | 回到上一层目录，最上是工作区的目录 |
| `d` | 把光标上的文件下载到本机的 `Downloads` |
| `/` | 在右上角打开搜索框 |

搜索框只查当前这一层目录（面板最右那一列）。输入即过滤，`↓` / `↑` 在命中之间移动；
`Enter`、`Esc` 或点一下这一片列都能关掉它；点中目录和 `l` 一样进入那一层，否则光标留在选中的那一项上。

## 下载

右键一个文件选「下载到 Downloads」，或把光标停在文件上按 `d`：文件从它所在的机器拷一份到本机的 `~/Downloads`，
名字照旧。本机已经有一个同名文件时新的那个加编号（`a.txt`、`a-1.txt`、`a-2.txt`），不覆盖已有的。目录不下载。

## 标签页

一个窗口给每个工作区留一份本插件的标签页，各显示各的列。
还没有显示目录的标签页，打开时取的是当时终端的目录（之后终端换目录不会再跟）。
